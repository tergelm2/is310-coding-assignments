# Gaming vs GPA CLI Data Entry

This is a script that collects data on how much students game, the name of the game, student name and their GPA.  

# How to Install:

```
python -m venv .venv
.venv\Scripts\Activate.ps1 # THIS IS FOR WINDOWS
# source .venv/bin/activate # for macOS/Linux
pip install -r requirements.txt
```


# How to Run:
```
python cli_data_entry.py
```
